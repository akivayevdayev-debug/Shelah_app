# Static assets notes

Everything the browser fetches from `/static/`, plus the service worker, manifest and offline page that Flask serves from the site root. The full account of how these pieces connect (import map, bridges, state, routing, theming, caching) is [`docs/FRONTEND.md`](../docs/FRONTEND.md); this file is the short orientation for the directory itself.

## Layout

| Path | What it is |
|---|---|
| `js/` | 31 ES modules, loaded through an import map with content-hashed URLs (`backend/module_versions.py`). No bundler. `main.js` is the entry point and publishes the `window.Shelah*` bridges the inline script in `templates/index.html` uses. Module inventory and responsibilities: `docs/FRONTEND.md` §2 |
| `css/tokens.css` | The design tokens: colour, spacing, radius, type, motion, for light and dark themes. Every other sheet consumes these; nothing else should hard-code a value that has a token |
| `css/*.css` | Per-surface sheets (`ai`, `calendar`, `calendar-detail`, `conversation`, `halacha`, `history`, `legal`, `loading`, `prayer`, `reader`, `siddur`, `sidebar`, `typography`) |
| `css/tailwind.input.css` → `css/tailwind.css` | Tailwind is built, not loaded from a CDN. Rebuild with `npm run build:css` after changing utility classes in a template or module, and commit the output |
| `style.css` | The legacy stylesheet (about 5,000 lines): reader row layouts, Hebrew typography defaults, sidebar and mobile-drawer behaviour. New rules go in a surface sheet or `tokens.css`; touch this file only when changing something that already lives here |
| `service-worker.js` | Served at `/service-worker.js` (registered as `?swv=3`); per-route caching strategies and the offline fallback. Bump the version when the precache list or a strategy changes. Behaviour table: `docs/FRONTEND.md` §10 |
| `offline.html` | The navigation fallback shown when the network and the cache both fail |
| `manifest.webmanifest`, `favicon*`, `apple-touch-icon.png`, `og-image.png` | Install and share metadata; outside the function route, so they are served by the CDN |
| `fonts/SILEOT.*` | The Ezra SIL Hebrew face, self-hosted |
| `data/glossary.json` | Generated by `scripts/generate_glossary_json.py`; do not edit by hand |

## Rules for changes here

- Animate only `transform` and `opacity`; honour `prefers-reduced-motion`. The AI mark (the star, the Ask button, the glow) is custom artwork and is not part of the Phosphor icon set; do not normalise it.
- Contrast is checked in both themes (`npm run test:a11y`). A change that only looks right in one theme is not finished.
- Static files are served with `Cache-Control: public, max-age=3600` (`vercel.json` header on `/static/*`). Modules are the exception: their URLs carry a content hash, so a changed module is a new URL.
- Tests for these files live in `tests_js/` (`npm test`), one file per module, with the service worker under `service_worker.test.js`.
